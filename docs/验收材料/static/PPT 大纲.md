# TransPasc 编译器项目汇报 PPT 大纲

## 第一部分：项目介绍 (5-6 页)

### 1. 项目概述

- **项目名称**：TransPasc-Compiler (KPC - King of Pascal Compiler)
- **项目背景**：北京邮电大学编译原理课程设计
- **指导教师**：王武凡
- **开发语言**：现代 C++（C++17/20），约 9,429 行代码
- **项目定位**：世界上最好的 Pascal 编译器

### 2. 项目特色功能

- 完整的 Pascal-S 语言编译器实现
- 多目标代码生成架构（C 代码、LLVM IR、RISC-V 汇编）
- 跨平台支持（Windows/Linux/macOS，x64/ARM64 架构）
- 现代化工程实践（CI/CD、代码规范、自动化测试）

### 3. 技术架构概览

- **分层模块化设计**：用户界面层 → 驱动控制层 → 编译前端 → 语义分析 → 代码生成 → 基础设施层
- **现代 C++技术栈**：智能指针、variant、format 等特性
- **工具链集成**：Flex 词法分析器、Bison 语法分析器、CMake 构建系统

### 4. 核心功能实现

- **词法分析**：关键字识别、标识符处理、三种注释格式、错误检测
- **语法分析**：LALR(1)分析、AST 构建、语法错误恢复
- **语义分析**：类型检查、作用域管理、符号表管理
- **代码生成**：C 代码生成（已实现）、预留 LLVM IR 和 RISC-V 接口

### 7. 测试体系概览

- **测试覆盖率**：集成测试 95%+通过率

- **支持平台**：6 种平台组合（3 个操作系统 × 2 种架构）
